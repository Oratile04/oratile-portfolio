# Statistical Modelling for Business Decision-Making

**Category:** Data Science / Statistical Analysis  
**Tools:** Python (pandas, numpy), R  
**Level:** Beginner–Intermediate  

---

## Objective
To apply statistical modelling techniques to a real-world business 
dataset — exploring relationships between variables, building a 
predictive model, and translating findings into actionable business 
insights.

---

## Tools Used
| Tool | Purpose |
|---|---|
| Python — pandas | Data loading, cleaning, and manipulation |
| Python — numpy | Numerical computation and array operations |
| R | Statistical analysis and model validation |

---

## Process

**Step 1: Define the business question**  
Before touching the data, I identified the core question the analysis 
needed to answer. Framing a clear business problem prevents aimless 
exploration and keeps the analysis focused on outcomes that matter.

**Step 2: Data collection & loading**  
Loaded the dataset using pandas, inspected its structure with `.head()`,
`.info()`, and `.describe()` to understand its shape, data types, 
and any obvious quality issues.

**Step 3: Data cleaning**  
Handled missing values, corrected data types, removed duplicates, 
and checked for outliers. Clean data is the foundation of any 
reliable model — garbage in, garbage out.

**Step 4: Exploratory Data Analysis (EDA)**  
Examined distributions, correlations, and relationships between 
variables. This step surfaces patterns and guides which modelling 
approaches are most appropriate.

**Step 5: Statistical modelling**  
Applied a suitable statistical model to the prepared dataset. 
Evaluated model performance using appropriate metrics such as 
R², RMSE, or accuracy depending on the problem type.

**Step 6: Interpreting & communicating findings**  
Translated model outputs into plain-language business insights. 
The goal was not just a working model, but a clear answer to the 
original business question.

---

## Findings
The analysis revealed meaningful relationships within the dataset 
that offered actionable direction for the business problem under 
investigation. Key variables were identified as significant drivers 
of the outcome being studied.

---

## Reflection & Learning
This project reinforced that data science is as much about asking 
the right questions as it is about running the right models. Working 
across both Python and R highlighted how each tool has its strengths 
— pandas for fast, flexible data wrangling; R for its robust 
statistical ecosystem. I also learned that communicating findings 
clearly is just as important as the technical work behind them.
